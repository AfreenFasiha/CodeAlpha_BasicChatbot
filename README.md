# 🤖 Basic Chatbot

## 📌 Project Overview

Basic Chatbot is a simple rule-based conversational chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users through predefined responses to common greetings and questions. It demonstrates the fundamentals of conversational programming using conditional statements, functions, loops, and user input handling.

---

## 🎯 Objective

To create a text-based chatbot that can:

* Greet users
* Respond to basic questions
* Continue conversations until the user exits
* Provide predefined responses based on user input

---

## ✨ Features

✅ Interactive command-line interface

✅ Responds to greetings like:

* Hello
* Hi
* Hey

✅ Answers common questions such as:

* How are you?
* What's your name?
* Who created you?

✅ Handles unknown inputs gracefully

✅ Exit command using:

* Bye
* Exit
* Quit

---
